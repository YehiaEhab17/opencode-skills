# opencode-skills

A collection of my personal [opencode](https://opencode.ai) skills.

Each skill is a self-contained folder with a `SKILL.md` plus the assets it needs
to run. Install by symlinking the skill folder into `~/.config/opencode/skills/`.

## Skills

| Skill | Description |
|---|---|
| `marp-presentation-creator` | Generate clean, professional Marp slides, with a reusable CSS "SmartArt" component library. |
| `report-generator` | Generate publication-ready LaTeX PDF reports from rough content. |
| `parsing-documents` | Extract text/images from PDF/Word/PowerPoint/etc. into AI-readable Markdown via MarkItDown. |
| `generating-revision-notes` | Generate revision notes and study guides from course material. |

## Notes

- Generated artifacts (`*.pdf` previews) and self-improvement notes
  (`lessons-learned.md`) are gitignored, regenerate with the bundled
  `generate-previews.sh` as needed.
